About Drupal Knowledge

Drupal Knowledge is an independent, evidence-backed knowledge system for Drupal, maintained by Zarabatana. Drupal Knowledge Community is the public and open-source edition, and this is its website.

What it holds

  • Structured Drupal knowledge — reviewed records, each with its sources and its trust class stated.
  • Source provenance — every source-derived record traces back to an immutable snapshot of the exact bytes it came from.
  • Security intelligence — Drupal Security Team advisories with the risk vector, CVEs and fixed releases as published.
  • Upgrade intelligence — upgrade transitions quoted from official Drupal documentation, and compatibility evaluation for a project.
  • API lifecycle information — deprecations and removals from api.drupal.org, and core change records.
  • Implementation guidance — reviewed implementation rules with explicit evidence requirements.
  • Solved cases — solutions proven in one specific context, kept to that context.
  • A command line, this generated website and a read-only public API, all reading the same published dataset.

How this site is made

Every domain page here is generated. Registered Drupal sources are acquired and stored as immutable snapshots; a changed source produces a detected change and a review candidate, never a changed record; records are projected from the snapshots a person has reviewed; one query layer answers questions about them; and this site is a rendering of that query layer's answers. The command line renders the same answers differently and reaches the same conclusions, because both read the same layer rather than the same files.

Published pages are generated artifacts. Canonical knowledge and the editorial pages — this one, the trust model, the CLI guide and the API guide — are maintained and reviewed in the repository, and the editorial pages contain no record data. Nothing here becomes trusted knowledge on its own: a source change is not a knowledge change, and a discovery signal is not knowledge.

What this site is not

  • It is not an analysis service. You cannot upload a project, and nothing is stored about you.
  • It has no accounts, no login and no comment threads.
  • It is not the programmatic interface. Tools should use the supported read-only public API, whose contract is versioned on its own; the JSON files behind these pages are internal build artifacts and not part of that contract.
  • It does not publish anything observed inside a private project.

Getting it

The repository is the distribution: github.com/zarabatana/drupal-knowledge.

cd drupal-knowledge
./dk status
