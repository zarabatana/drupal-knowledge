About Drupal Knowledge

Drupal Knowledge Community: an independent, evidence-backed knowledge system for Drupal, maintained by Zarabatana.

How this site is made

Every domain page here is generated. Registered Drupal sources are acquired and stored as immutable snapshots; records are projected from those snapshots; one query layer answers questions about them; and this site is a rendering of that query layer's answers. The command line renders the same answers differently and reaches the same conclusions, because both read the same layer rather than the same files.

Nothing on a record page was written by hand. The editorial pages — this one, the trust model and the CLI guide — were, and they contain no record data.

What this site is not

  • It is not an analysis service. You cannot upload a project, and nothing is stored about you.
  • It has no accounts, no login and no comment threads.
  • It is not an API. The JSON files behind this site are build artifacts whose shape may change; a supported API is a separate piece of work.
  • It does not publish anything observed inside a private project.
