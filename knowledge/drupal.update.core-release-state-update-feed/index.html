Drupal core release state comes from the official update feed

Reviewed Drupal Knowledge trusted knowledge, reviewed by a human against authoritative sources

A human reviewed this against registered authoritative sources. It states something about Drupal, not about any one project.

The official Drupal update-status release-history feed exposes project status, supported branches, release versions, release types, and security coverage, so release-aware knowledge should watch that source instead of hard-coding the latest Drupal version.
