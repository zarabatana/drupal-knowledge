Use Drupal database placeholders instead of concatenating SQL

Reviewed Drupal Knowledge trusted knowledge, reviewed by a human against authoritative sources

A human reviewed this against registered authoritative sources. It states something about Drupal, not about any one project.

Drupal secure-code documentation says data must never be concatenated directly into SQL queries and directs developers to use proper argument substitution, select queries, escapeLike() for LIKE values, and fixed operator choices.
