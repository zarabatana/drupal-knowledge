Current Drupal Coding Standards are on GitLab Pages

Reviewed Drupal Knowledge trusted knowledge, reviewed by a human against authoritative sources

A human reviewed this against registered authoritative sources. It states something about Drupal, not about any one project.

The Drupal Coding Standards project links to the current GitLab Pages standards, while the historical Drupal.org coding standards guide is marked obsolete and deprecated; the current standards state that they are version-independent and always-current.
