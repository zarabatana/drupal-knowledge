Twig output escaping should not be bypassed without trusted data

Reviewed Drupal Knowledge trusted knowledge, reviewed by a human against authoritative sources

A human reviewed this against registered authoritative sources. It states something about Drupal, not about any one project.

Drupal secure-code documentation says Twig auto-escapes printed strings by default, warns that the raw filter does not escape output and should only be used for trusted data, and states that rendered Twig attributes should be quoted.

Record drupal.security.twig-output-escaping
