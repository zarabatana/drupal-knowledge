The command line

The same knowledge on this website, plus the ability to ask about your own Drupal project. Everything it does is read-only.

Install

Drupal Knowledge is a repository, not a package. There is no Composer package, no Homebrew formula and no binary release — clone it and run it. It needs Python 3 and nothing else. 

git clone https://github.com/zarabatana/drupal-knowledge.git
cd drupal-knowledge
./dk status

Add the directory to your PATH to run dk from anywhere. Queries are offline: the records ship in the repository and no command below contacts the network.

The five things people ask

dk status                        what this release knows, and how current it is
dk project /path/to/project      inspect a Drupal project, read-only
dk search file_create_url        advisories, APIs, rules and reviewed knowledge
dk explain SA-CORE-2025-001      why a record exists and what supports it
dk provenance <record-id>        trace a record back to its source snapshot

Add --target 11.4.6 to dk project to get the upgrade assessment and the custom-code migration work for that version. Add --json to any of the five for machine-readable output.

The exit code reports whether the query succeeded, not whether your project is healthy. A project with applicable advisories still exits zero. Read the findings, not the exit code.
